#Página de Receita – Cupcake

Projeto simples desenvolvido com **HTML e CSS**, apresentando uma receita de cupcake.

## Sobre

A página contém:

- Imagem ilustrativa
- Descrição da receita
- Lista de ingredientes
- Modo de preparo
- Estilização com CSS

##Tecnologias

- HTML5
- CSS3


##Como Executar

Abra o arquivo `index.html` no navegador.
